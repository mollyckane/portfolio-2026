# Portfolio 2026

My personal portfolio site, built to showcase my software development projects.

Live at [mollyckane-sdev.vercel.app](https://mollyckane-sdev.vercel.app/)

## Built with

- Next.js
- React
- CSS / Tailwind

## Project structure

- `src/app` - pages and layouts
- `src/components` - reusable UI components
- `src/data` - project and content data
- `src/styles` - global styles

## Getting started

```bash
npm install
npm run dev
```

Open `http://localhost:3000` to view it.
